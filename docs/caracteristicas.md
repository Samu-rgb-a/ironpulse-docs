# Diseñado para rendir en el gimnasio

La interfaz de **IronPulse** está optimizada para que no pierdas tiempo entre series navegando por menús complejos.

## Creación y personalización de rutinas

Organiza tus entrenamientos con total flexibilidad:

1. Elige ejercicios de una base de datos con más de **400 movimientos** con animaciones explicativas.
2. Define el rango objetivo de repeticiones y la intensidad esperada (RPE o RIR).
3. Activa el cronómetro de descanso automático entre series.

## Tipos de series admitidas

Puedes categorizar cada serie para llevar un control exacto del esfuerzo:

| Tipo de serie | Propósito | Indicador visual |
| :--- | :--- | :--- |
| **Normal** | Serie de trabajo principal | Azul |
| **Calentamiento** | Preparación muscular sin fatiga | Amarillo |
| **Al fallo** | Esfuerzo llevado al límite muscular | Rojo |
| **Drop Set** | Reducción inmediata de la carga | Morado |

## Parámetros registrados por serie

En cada serie podrás anotar de forma rápida:

* **Peso levantado**: Ajuste en kilogramos o libras.
* **Repeticiones conseguidas**: Registro del número exacto completado.
* **Estado de la serie**: Marca de verificación instantánea para activar el temporizador de descanso.
